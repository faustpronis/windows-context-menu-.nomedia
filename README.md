# FolderTools

[![release](https://img.shields.io/github/v/release/faustpronis/windows-context-menu-.nomedia?display_name=tag&sort=semver)](https://github.com/faustpronis/windows-context-menu-.nomedia/releases/latest)

Небольшая утилита для Windows, которая добавляет в контекстное меню папки пункт
**FolderTools** с подпунктами:

1. **Создать .nomedia** — создаёт (или дополняет) в текущей папке файл `.nomedia`
   с отметкой времени и путём этой папки.
2. **desktop.ini (DeskEdit)** — открывает текущую папку в редакторе `desktop.ini`
   [Desktop.ini Editor](https://www.sordum.org/10084/desktop-ini-editor-v1-2/) (DeskEdit).
3. **Настройки…** — открывает окно настройки папок для копирования и перемещения.

Пункт появляется при клике правой кнопкой по папке, по пустому месту внутри папки
и по корню диска. Регистрация идёт в `HKEY_CURRENT_USER`, права администратора не нужны.

## Пункт в меню «Создать»

После установки в меню **Создать** (правый клик по пустому месту в папке) появляется
пункт **Файл .nomedia**. Он создаёт `.nomedia` с текущей датой, временем и путём папки —
как команда «Создать .nomedia», но одним движением.

Техническая деталь: `ShellNew` в реестре не умеет задать точное имя файла — оболочка
сама придумывает имя («Новый файл.nomedia») и затем передаёт его команде. Поэтому
пункт зарегистрирован через значение `Command`, а не `NullFile`: утилита получает
этот файл-заглушку, пишет настоящий `.nomedia` в ту же папку и удаляет заглушку.
Значит, пункт работает и тогда, когда `.nomedia` в папке уже есть, — запись просто
дополнится по общим правилам.

Ограничение: меню «Создать» есть только у папок на диске (в проводнике). В диалогах
открытия/сохранения файлов и на рабочем столе пункта не будет.

## Что пишется в .nomedia

Первая строка — время и дата, вторая — путь к папке:

```
18:53:23  18.11.2026 Ср
D:\SHARE\SYNCTHING\
```

Правила:

- Формат даты и дня недели не зависит от региональных настроек Windows:
  дни недели жёстко заданы (`Пн`…`Вс`), формат — `ЧЧ:ММ:СС  ДД.ММ.ГГГГ`.
- Если файла `.nomedia` нет — он создаётся.
- Если файл есть, но записи для этой папки в нём нет — новая запись добавляется
  в конец, отделённая пустой строкой.
- Если запись для этой папки уже есть (путь сравнивается без учёта регистра
  и типа разделителей) — ничего не меняется.
- Кодировка — UTF-8 без BOM, перевод строки — CRLF.

## Установка

1. Распакуйте архив целиком, например в `C:\Tools\FolderTools`. DLL находятся в
   подпапке `FolderTools_dlls`; не отделяйте её от программы. Рядом с `FolderTools.exe`
   должен оставаться `FolderTools.exe.config` — он указывает загрузчику .NET искать
   библиотеки в этой подпапке и содержит необходимые перенаправления сборок.
   Папку установки потом не перемещайте: путь к exe записывается в реестр.
2. Запустите `install.bat`. Он удаляет оставшиеся рядом с exe DLL от старых версий,
   затем регистрирует меню. Для обновления поверх предыдущей установки это важно.
   Вместо BAT можно выполнить `FolderTools.exe -i`, если рядом с exe не осталось
   старых DLL.
3. Правый клик по папке (или по пустому месту внутри неё) → **FolderTools**.

`FolderTools.exe.config` — конфигурация CLR для .NET Framework 4.8. Загрузчик
читает её до запуска приложения, поэтому перенести её в `FolderTools_dlls` нельзя;
обычный .NET Framework также не поддерживает встраивание этого файла в exe.

Удаление — `FolderTools.exe -r` или `uninstall.bat`.

## Копировать в / Переместить в

В контекстном меню файлов действия **«Копировать в»** и **«Переместить в»** собраны
в одном пункте **FolderTools** с иконкой приложения; внутри также всегда доступен
пункт **«Настройки…»**. Для папок назначения (при клике по папке) действия остаются
отдельными пунктами. Список папок назначения и правила отбора задаются в окне
настроек («FolderTools → Настройки…» или `FolderTools.exe settings`).

Для каждой папки назначения задаётся название, путь и список шаблонов расширений:

| Шаблон | Что означает |
|---|---|
| `*` | любой файл, в том числе без расширения |
| `*.txt` | все файлы `.txt` |
| `*.jp!` | `.jpg`, `.jpeg`, `.jpX` — `!` это ровно один любой символ |
| `фото!.jpg` | `фото1.jpg`, `фотоA.jpg`, но не `фото10.jpg` |
| `txt` | то же, что `*.txt`: точку можно не писать |
| `[папка]` | только папки |

Регистр не важен. Шаблонов у одной папки может быть несколько — они объединяются.

Поведение меню:

- Пункт папки виден только для тех файлов, чьё расширение подходит под её шаблоны.
- Если выделено несколько файлов разных типов, каждый файл уходит в свою папку:
  расширение проверяется отдельно для каждого файла, а не для всего выделения сразу.
- Папки назначаются отдельно (`[папка]`), чтобы файлы и каталоги не смешивались.
- Одинаковые имена не перезаписываются: к имени добавляется ` (2)`, ` (3)` и так далее.
- Целевая папка создаётся, если её ещё нет.

### Удалённые папки SFTP

Нажмите **«Добавить SFTP»** в настройках папок назначения и укажите название,
сервер, порт, удалённый путь, пользователя и пароль. Кнопка **«Проверить соединение»**
проверяет авторизацию и доступность папки. При первом подключении программа покажет
SHA-256 fingerprint SSH-ключа сервера. Сверьте его с администратором сервера до
подтверждения: после этого fingerprint запоминается, и дальнейшие подключения
отклонят другой ключ.

Действие **«Копировать в»** загружает выбранные файлы и папки, включая вложенные
каталоги. **«Переместить в»** удаляет локальный оригинал только после успешной
загрузки. Существующие файлы не перезаписываются; при совпадении имени добавляется
` (2)`, ` (3)` и так далее.

Логин и пароль не записываются в `FolderTools.settings.json`: они защищены Windows
DPAPI и хранятся отдельно для текущей учётной записи в `%LOCALAPPDATA%\FolderTools`.
На новом компьютере или под другой учётной записью Windows пароль нужно ввести
заново в настройке SFTP-папки. Конфигурация SFTP хранит только адрес сервера,
удалённый путь и доверенный fingerprint.

### Категории

Чтобы меню не разрасталось, папки можно объединить в категории. Категория — это
подменю: например «Фото» → «Снимки», «Скрины». Папки без категории остаются в корне.
Удаление категории не удаляет папки, они возвращаются в корень.

### Иконки пунктов меню

У каждой папки можно задать свою иконку: выберите пункт в списке и нажмите
«Обзор…» в строке «Иконка». Выбранный `.ico` копируется в подпапку `icons`
рядом с программой (создаётся автоматически), а в настройках сохраняется
относительный путь `icons\<id>.ico`. Поэтому папку с программой можно целиком
перенести или заархивировать, не теряя иконки. Если файл иконки удалить,
пункт вернётся к иконке программы.

### Где хранятся настройки

Всё лежит рядом с программой, в одной папке:

- `FolderTools.settings.json` — папки назначения, шаблоны расширений, категории,
  настройки SFTP без паролей, иконки, путь к DeskEdit и уведомления;
- `icons\` — копии выбранных иконок.

Пароли SFTP защищены DPAPI и хранятся отдельно в профиле текущей учётной записи:
`%LOCALAPPDATA%\FolderTools\sftp-credentials.dat`.

Пути внутри папки программы записываются относительными, поэтому перенос папки
ничего не ломает. Меню перестраивается сразу при сохранении в окне настроек;
перезапуск проводника не нужен, но уже открытое меню нужно закрыть.

## DeskEdit (desktop.ini)

Утилита не включает в себя DeskEdit. Скачайте его со страницы
<https://www.sordum.org/10084/desktop-ini-editor-v1-2/>, распакуйте, например в
`C:\Tools\DeskEdit`, и укажите путь:

```
FolderTools.exe set-deskedit "C:\Tools\DeskEdit\DeskEdit_x64.exe"
```

Путь можно задать и в окне настроек, на вкладке «Прочее». Утилита ищет редактор
в таком порядке: `deskEditPath` из `FolderTools.settings.json` (старые сборки
писали его в реестр — это значение читается как запасной вариант), файл рядом
с `FolderTools.exe`, `C:\Tools\DeskEdit\DeskEdit_x64.exe` и
`C:\Tools\DeskEdit\DeskEdit.exe`.

Редактор запускается с путём папки в качестве параметра
(`DeskEdit_x64.exe "D:\My_Folder"`) — такую форму поддерживает сам DeskEdit.

## Команды

| Команда | Действие |
|---|---|
| `FolderTools.exe settings` | Открыть окно настроек |
| `FolderTools.exe -i`, `--install` | Зарегистрировать пункт в контекстном меню папок |
| `FolderTools.exe -r`, `-remove`, `--uninstall` | Убрать пункт из контекстного меню |
| `FolderTools.exe -v`, `--version` | Показать версию |
| `FolderTools.exe nomedia "<папка>"` | Создать или дополнить `.nomedia` |
| `FolderTools.exe shellnew "<файл>"` | Обработать заглушку из меню «Создать» |
| `FolderTools.exe deskedit "<папка>"` | Открыть `desktop.ini` папки в DeskEdit |
| `FolderTools.exe set-deskedit "<путь>"` | Запомнить путь к `DeskEdit.exe` |
| `FolderTools.exe -h`, `--help` | Справка |

Без аргументов открывается окно настроек — так удобнее при запуске двойным
кликом по `FolderTools.exe`. Справка вызывается флагом `-h` / `--help`. Если
утилиту запустили из консоли, результат печатается в неё; при запуске двойным
кликом — показывается окно.

Все настройки хранятся в файле `FolderTools.settings.json` рядом с программой:
папки назначения, шаблоны, категории, иконки, `deskEditPath` и `showSuccess`.
Реестр `HKCU\Software\FolderTools` используется только для регистрации меню
и для чтения значений, записанных старыми версиями.

## Сборка

```
dotnet build FolderTools.sln -c Release
dotnet test src/FolderTools.Tests/FolderTools.Tests.csproj
```

Приложение — это .NET Framework 4.8 (WinForms), поэтому собирается на Windows.
Тесты и ядро — на .NET 8 / netstandard2.0, их можно прогонять и на Linux.
Иконка приложения генерируется скриптом `tools/make_icon.py` в `assets/app.ico`.

CI (GitHub Actions, `.github/workflows/build.yml`) собирает проект и прогоняет тесты.
При пуше тега вида `v0.8.0` версия из тега подставляется в сборку, проверяется,
что она попала в exe, и публикуется релиз с архивом `FolderTools-<версия>.zip`.
При обычном пуше в `main` тот же архив лежит в артефактах прогона.

## Структура

```
src/FolderTools.Core     логика: формат времени, .nomedia, запуск DeskEdit, разбор аргументов
src/FolderTools.App      WinForms-приложение и регистрация пункта меню
src/FolderTools.Tests    тесты (xUnit)
installer/               install.bat / uninstall.bat
tools/make_icon.py       генератор assets/app.ico
```
